## 🎨 DESIGN-SYSTEM

### Farbpalette
| Rolle | Farbe | Hex |
|---|---|---|
| Primärfarbe (CTA, Badges) | Brand Blue | #125dff |
| Dunkel-Akzent | Brand Blue Dark | #1d4ed8 |
| Hintergrund Hell | Soft Blue | #eff6ff |
| Text Primary | Slate 900 | #0f172a |
| Text Secondary | Slate 600 | #475569 |
| Weiß (Karten) | Pure White | #ffffff |

### Typografie
- Headlines: Montserrat Black (900) / ExtraBold (800)
- Subheadings: Montserrat Bold (700)
- Body / Caption: Montserrat Medium (500)
- Badges & Tags: Montserrat SemiBold (600)

### Wiederkehrende Design-Elemente
- Pill-Badges oben auf Slide 1: [ SHK-TIPP ] [ LIVE-FEATURE ] [ ROI & FÖRDERUNG ]
- Trust-Checkmarks auf letzter Folie: ✓ Kein App-Download | ✓ DSGVO | ✓ Made in Germany
- Bento-Grid-Stil: Abgerundete Ecken (16–24px), subtile Schatten
- Dark Cover-Slides: Slate-900 Hintergrund + weißer Text + Brand-Blue-Badge (für Hooks)
- Light Info-Slides: Weißer Hintergrund + Slate-Text + blaue Akzente (für Inhalt)
