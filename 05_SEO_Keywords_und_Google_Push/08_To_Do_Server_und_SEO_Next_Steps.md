# 📌 tele-LOOK Marketing & Technik – Next Steps & Server-To-Dos (2026)

## 🖥️ Server-Einstellungen (Host Europe KIS Dashboard)
- [ ] **Charset auf `UTF-8` umstellen:** 
  - *Pfad:* Host Europe KIS -> Skript-Einstellungen -> Charset -> `ändern` -> `UTF-8`.
  - *Ziel:* Verhindert serverseitige Umlaut-Codierungsfehler bei PHP-Seitenaufrufen.
- [ ] **`PHP-allow_url_fopen` auf `On` setzen:**
  - *Pfad:* Host Europe KIS -> Skript-Einstellungen -> PHP-allow_url_fopen -> `ändern` -> `On`.
  - *Ziel:* Optimiert API-Kommunikation für Google Site Kit, Rank Math & Elementor.
- [ ] **`PHP-Errors` Logging aktivieren:**
  - *Pfad:* Host Europe KIS -> Skript-Einstellungen -> PHP-Errors -> `Logging in Logfile: On`.
